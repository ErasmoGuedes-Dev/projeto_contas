
## Descrição - Java SpringMVC
O **Projeto Contas**  é um projeto de Controle Financeiro desenvolvido em Java Spring MVC 
que permite aos usuários gerenciar suas contas a pagar e a receber. 
O projeto utiliza o banco de dados PostgreSQL para armazenar os dados.

## Pré-requisitos
Antes de executar o projeto, certifique-se de ter instalado os seguintes componentes:
- [Apache Tomcat 9](http://tomcat.apache.org/download-90.cgi)
- [PostgreSQL 15](https://www.postgresql.org/download/)

## Tecnologias Utilizadas

- **Java**: 17
- **Spring Framework**: 3.1.0.RELEASE
- **PostgreSQL**: Banco de dados utilizado para persistência
- **JSP**: Para criação das páginas dinâmicas
- **Bootstrap**: Para estilização e responsividade

## Dependências

As dependências do projeto estão definidas no arquivo `pom.xml` e incluem:

- Spring Context
- Spring Web MVC
- Spring ORM
- PostgreSQL Driver
- Lombok
- JSTL (JavaServer Pages Standard Tag Library)
  
## Objetivo

O objetivo deste projeto é fornecer uma solução prática e eficaz para o controle de contas, 
permitindo ao usuário monitorar facilmente suas despesas e receitas.
